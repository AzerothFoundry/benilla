# 桌宠升级与回退

应用版本（如0.4.9）和配置格式版本（当前schema_version=1）分别管理，不为每次发布强制迁移配置。

## 升级

1. 正常退出桌宠所有实例，替换应用程序包；不要删除用户配置目录。当前本机发布流程另保留旧.app备份。
2. 启动新版。没有版本字段的历史配置视为格式0，使用原有兼容读取逻辑保留角色连接、选中项、资源路径、位置、缩放、外观与特效偏好；缺少的新字段填默认值。自定义未知JSON字段在本次迁移中保留。
3. 配置迁移持有文件锁，先把原始字节同步备份至配置旁backups/settings-v0-<唯一标识>.json，再使用临时文件+同步+原子重命名发布新配置。再次启动是幂等操作。
4. 更高版本或损坏配置会报错，保留原文件；正常保存路径也会拒绝覆盖。图标导出/帮助命令不主动执行配置迁移。

macOS配置目录为~/Library/Application Support/AzerothFoundry/companion。连接与外观缓存不随替换.app删除；新增profiles缓存按连接ID和URL隔离，只保留角色种族、等级、职业、地区等展示信息。没有种族信息时使用原版通用登录场景，场景资源缺失时仍保留深色界面背景。

## 回退

先退出所有实例，保留当前配置副本，再恢复旧.app。若旧版本不兼容当前配置格式，恢复本次升级生成的原始配置备份。不要假设尚未实现版本检查的历史二进制会识别新格式；其保存行为可能丢弃不认识的字段。外观/角色元数据缓存是可重建缓存，未变化的连接URL仍使用同一身份键。

本轮提供的是本地配置迁移和有备份的发布流程，不包含自动联网下载、自动更新服务或游戏服务器/数据库迁移。旧版并发写配置存在互相覆盖格式字段的可能，因此升级/回退前应关闭所有桌宠实例。

## 验证

覆盖无版本的旧配置、新字段默认值、旧单URL格式、偏好与未知字段保留、原始备份字节一致、重复执行不重复备份，以及更高版本/损坏文件不覆盖。替换应用前后另验证签名与二进制哈希，保留发布回执。
